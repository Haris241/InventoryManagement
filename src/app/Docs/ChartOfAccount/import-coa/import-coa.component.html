rule Before You Start

  • Use the latest template supplied by the system.
  • Do not rename the Import sheet.
  • Do not change, rename, add, or remove the expected column headers.
  • Do not enter database Account IDs.
  • Enter one account per row.
  • Remove any sample rows before uploading if they're not meant to be imported.

account_tree RowRef, ParentRef & ParentCode

Account codes are generated automatically. RowRef and ParentRef let you build a hierarchy even when the parent doesn't have a generated code yet.

A001 · Inventory · ParentCode 100001 · Group · Asset
A002 · Raw Material · ParentRef A001 · Ledger · Asset
A003 · Finished Goods · ParentRef A001 · Ledger · Asset

Inventory is created under existing account 100001. Raw Material and Finished Goods use ParentRef A001, so the system links them to the newly created Inventory account.

alt_route Which Parent Field Should I Use?

  • Use ParentCode when the parent account already exists in the Chart of Accounts.
  • Use ParentRef when the parent account is another row in the same file.
  • Never provide both ParentCode and ParentRef for the same row.
  • The parent must be a Group account, and it must share the child's Category.

tune Allowed Values

Kind
Group — parent/folder, not postable Ledger — postable, receives transactions
Category
Asset Liability Equity Revenue Expense
Account Usage (optional)
None Cash Bank Customer Supplier Tax

Cash and Bank must be Asset accounts. Customer and Supplier must be Asset or Liability accounts. Group accounts shouldn't use a special usage.

payments Opening Balance & Account Codes

  • Opening Balance is optional and must not be negative.
  • Enter a plain numeric value with no currency symbol — e.g. 25000.
  • The system posts the opening balance entry for you.
  • Never enter a final account code — codes are generated automatically by category and configured range.

sync What Happens After Upload?

  1. 1

    The system reads the Import sheet — the Instructions sheet is ignored.

  2. 2

    Workbook structure and column headers are checked.

  3. 3

    Rows are parsed and validated.

  4. 4

    Existing parents are resolved through ParentCode; new parents through RowRef/ParentRef.

  5. 5

    Account codes are generated automatically.

  6. 6

    If validation passes, accounts are created. If it fails, nothing is imported and errors are returned for correction.

warning Important Rules

  • Never enter database Account IDs or manually assign account codes.
  • Keep every RowRef unique.
  • Don't rename the Import sheet or change column names.
  • Remove example/sample rows before uploading if they're not meant to be imported.
